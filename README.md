## Project Overview

The IoT Weather Station is designed to monitor environmental conditions such as temperature and humidity using sensors connected to an ESP32 microcontroller.

## Project Scope

This project demonstrates real-time weather monitoring using IoT technology and cloud-connected devices.

## Objectives

* Monitor temperature and humidity
* Understand sensor integration
* Learn IoT data collection
* Build an environmental monitoring system
