# IoT Weather Station

## Introduction

The IoT Weather Station is a smart environmental monitoring system that measures temperature and humidity using a DHT22 sensor connected to an ESP32 microcontroller.

## Objective

The objective of this project is to monitor weather conditions and demonstrate real-time environmental data collection using IoT technology.

## Components Used

* ESP32
* DHT22 Sensor
* Wi-Fi
* Arduino IDE
* Wokwi Simulator

## Working Principle

1. The DHT22 sensor measures temperature and humidity.
2. ESP32 reads the sensor values.
3. The measured values are displayed through the Serial Monitor.
4. Data can be monitored continuously in real time.

## Advantages

* Real-time monitoring
* Low-cost implementation
* Easy to use
* Useful for environmental analysis

## Applications

* Smart homes
* Weather monitoring systems
* Agriculture monitoring
* Research projects

## Conclusion

The IoT Weather Station demonstrates how sensors and IoT devices can be used to monitor environmental conditions efficiently and accurately.
